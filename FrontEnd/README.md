# CineMax Static HTML UI

A static HTML/CSS/JavaScript version of the cinema ticket booking UI.

## Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Tailwind CSS via CDN

## Structure

```text
cinemax-static-html/
├── index.html
├── assets/
│   ├── css/
│   │   └── styles.css
│   └── js/
│       ├── data.js
│       └── app.js
└── README.md
```

## Run

Open `index.html` directly in a browser, or serve the folder with any static server:

```bash
python -m http.server 8080
```

Then visit `http://localhost:8000`.

No React, JSX, TypeScript, Vite, or build tooling is included.
